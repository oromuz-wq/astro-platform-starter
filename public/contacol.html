🚀 Inicio Rápido
  1. Vaya a Empresas → Agregar Empresa
  2. Complete nombre, NIT y token DIAN
  3. Toque la empresa para seleccionarla
  4. Vaya a DIAN → Verificar Conexión
  5. Defina rango de fechas → Descargar Facturas
  6. Vea resultados en Facturas
🔑 Dónde obtener el Token DIAN
  1. Ingrese al portal DIAN Facturación Electrónica
  2. Menú → Configuración → Token
  3. Copie el valor JWT (empieza con eyJ)
  4. Péguelo en el campo Token de esta app
⚠️ Error CORS en PC
Si abre la app desde un archivo local (file://), el navegador bloqueará las llamadas a la API. Solución:

python3 -m http.server 8080
Luego abra http://localhost:8080
📱 Instalar en Celular
Android (Chrome): Menú → "Añadir a pantalla de inicio"

iPhone (Safari): Compartir → "Añadir a inicio"

La app funciona sin internet para ver facturas ya descargadas.
